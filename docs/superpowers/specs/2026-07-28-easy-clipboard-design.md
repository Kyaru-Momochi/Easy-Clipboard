# Easy Clipboard 产品与技术设计

日期：2026-07-28  
状态：已确认，等待规格文件复核  
目标平台：Windows 10/11 x64

## 1. 产品目标

Easy Clipboard 是一款轻量、现代、不会打断输入流的 Windows 剪贴板历史工具。它常驻系统托盘，通过 `Ctrl + Shift + V` 呼出置顶浮窗，保存最近 100 条普通剪贴记录，并支持文本、图片、文件、音频和视频等常见内容。

首版只支持 Windows 10/11 x64。发行物为单个 NSIS 安装器 `.exe`，保存到仓库的 `release` 目录，并发布到 GitHub Release。

## 2. 已确认的产品约束

- 普通历史最多保存 100 条。
- 文件、音频和视频只记录原文件路径与元信息，不复制文件本体。
- 单次复制的默认体积上限为 50 MB，可在 1–500 MB 范围内调整。
- 超限内容静默忽略。
- 默认全局热键为 `Ctrl + Shift + V`，允许自定义。
- 浮窗置顶，点击历史项不使呼出前的输入框失焦。
- 点击历史项默认直接粘贴；右键提供仅复制等补充操作。
- 关闭主窗口时缩入托盘；开机启动默认关闭。
- 主题支持跟随系统、浅色、深色三档；默认跟随系统。
- 浅色采用“极光玻璃”视觉，深色采用“深色墨影”视觉。
- 主题切换采用约 200 ms 的平滑过渡。
- 数据仅保存在本机，不联网、不上传、不收集遥测。

## 3. 技术路线

### 3.1 技术栈

- Tauri 2：桌面窗口、打包和前后端桥接。
- Rust：Windows 剪贴板监听、全局热键、窗口焦点、历史策略和本地存储。
- Svelte + TypeScript：响应式界面、主题、搜索、筛选和动效。
- SQLite：历史元数据、文本内容、设置与迁移版本。
- 文件资源目录：图片的无损 PNG 数据与缩略图。
- NSIS：Windows x64 单文件安装器。

Tauri 使用系统 WebView2，在保持较小安装体积和常驻内存的同时，为两套主题提供足够的 CSS 动效能力。

### 3.2 模块边界

#### Windows 原生层

负责监听 `WM_CLIPBOARDUPDATE`、读取和写入 Windows 剪贴板、注册全局热键、跟踪呼出前的前台窗口、显示无激活置顶浮窗，以及向原窗口发送粘贴操作。

#### 历史与策略层

把 Windows 剪贴板格式规范化为文本、图片和文件三类记录。该层负责格式优先级、体积计算、内容指纹、去重、历史淘汰、收藏与搜索模型。

#### 本地存储层

使用 SQLite 事务保存结构化元数据。图片原图和缩略图位于应用数据目录。文件类记录只包含路径、名称、扩展名、媒体分类、大小和可用状态。

#### 界面层

Svelte 界面只通过受限 Tauri 命令读取状态或触发操作，不直接调用系统 API。主浮窗与普通设置窗口分离。

## 4. 内容模型与格式处理

### 4.1 规范化类型

- `Text`：纯文本为必选表示；剪贴板同时提供 HTML 或 RTF 时，在体积限制内一并保存。
- `Image`：保存无损 PNG 原图、缩略图、像素尺寸和字节数。
- `Files`：保存一个或多个文件或目录的路径与元信息。音频、视频依据扩展名和系统 MIME 信息呈现专属类型。

同一次复制可能同时出现多个 Windows 格式。归类优先级为文件列表、图片、富文本/纯文本，确保一次复制只生成一条记录。

### 4.2 体积限制

- 文本按最终保存的编码后字节数计算。
- 图片按保存数据的字节数计算。
- 文件列表按原文件总大小计算。
- 目录在后台进行有上限的遍历；一旦累计值超过阈值即停止，不阻塞剪贴板监听线程。
- 默认上限 50 MB，设置允许 1–500 MB。
- 超限内容不写入历史，也不弹出通知。

### 4.3 去重与保留

每条内容拥有稳定指纹。重复复制不会产生重复记录，而是更新原记录的时间并移动到列表顶部。

普通历史保留最近 100 条。收藏区额外保留最多 20 条，不参与普通历史淘汰。达到收藏上限时，界面明确提示用户先取消已有收藏。

### 4.4 不可用文件

当记录指向的文件被移动或删除时，卡片显示“原文件不可用”。该记录不能直接粘贴，但仍允许打开原目录、仅复制现有路径信息或删除记录。

## 5. 窗口与焦点模型

### 5.1 主浮窗

主浮窗使用 Windows 无激活置顶样式。按热键呼出时记录当前前台窗口句柄，并在当前显示器中央显示约 `460 × 620` 的窗口。用户可以拖拽和缩放，窄尺寸自动切换为紧凑布局。

鼠标点击历史项时：

1. 将该项以合适格式写入系统剪贴板。
2. 保持或恢复呼出前窗口为粘贴目标。
3. 向目标窗口发送粘贴组合键。
4. 播放轻微反馈并隐藏浮窗。

该流程不把主浮窗变为前台激活窗口。

### 5.2 临时键盘接管

主浮窗显示期间安装最小范围的临时键盘处理，只用于：

- 输入搜索关键词；
- 上下移动选中项；
- `Enter` 粘贴；
- `Esc` 关闭。

处理仅在浮窗可见时启用，不保存按键内容，不向网络发送数据，关闭浮窗后立即解除。设置窗口是普通激活窗口，不使用此机制。

### 5.3 托盘与生命周期

应用启动后常驻托盘。关闭主浮窗等同于隐藏。托盘菜单包含显示、暂停监听和退出。设置中提供开机启动开关，默认关闭。

## 6. 界面与主题

### 6.1 信息结构

主浮窗由以下区域组成：

- 标题与状态；
- 即时搜索；
- 全部、文本、图片、文件筛选；
- 响应式历史卡片列表；
- 历史数量和设置入口。

文本卡片显示内容摘要；图片卡片显示缩略图、尺寸和体积；文件卡片显示图标、名称、大小、路径和媒体类型。

右键菜单包含仅复制、收藏/取消收藏、删除和打开文件位置。

### 6.2 视觉方向

- 浅色：极光玻璃。使用柔和冷色渐变、半透明表面和克制微光。
- 深色：墨影专业。使用高对比深灰表面、细边框和紫色聚焦状态。
- 跟随系统：监听 Windows 主题变化并自动切换。

主题变化约 200 ms。呼出、隐藏、筛选和卡片操作使用 160–240 ms 的淡入、位移与弹性反馈。检测到 Windows“减少动画”时禁用非必要动画。

## 7. 设置

设置窗口包含：

- 自定义全局热键；
- 单次内容上限，范围 1–500 MB；
- 跟随系统、浅色、深色主题；
- 动画强度；
- 开机启动；
- 退出时清空；
- 一键清空普通历史；
- 应用版本与本地数据目录。

无效设置不会写入数据库。设置损坏或迁移失败时回退到安全默认值，并保留历史数据。

## 8. 数据流与容错

1. 原生窗口收到剪贴板更新通知。
2. 读取器在剪贴板被其他程序占用时进行短暂、有限次数重试。
3. 原始格式被规范化，体积计算在后台完成。
4. 超限项目静默丢弃；合格项目计算指纹。
5. 历史服务在事务中执行去重、插入和淘汰。
6. 前端收到轻量事件并更新列表。
7. 粘贴时重新检查文件可用性，写回多格式剪贴板并发送粘贴。

数据库使用事务和版本迁移。图片文件先写入临时文件，再原子替换。异常退出后启动检查会清理孤立临时文件和无引用资源。

## 9. 测试策略

### 9.1 自动测试

Rust 单元测试覆盖：

- 格式优先级；
- 默认值和设置范围；
- 1–500 MB 体积限制；
- 指纹与去重；
- 100 条普通历史淘汰；
- 20 条收藏限制；
- 不可用文件状态；
- 搜索和筛选模型。

前端测试覆盖：

- 类型筛选；
- 搜索结果；
- 主题状态；
- 设置校验反馈；
- 响应式布局状态；
- 减少动画策略。

### 9.2 集成与实机测试

通过可替换剪贴板后端验证“捕获、保存、选择、恢复格式、粘贴”的完整链路。Windows 实机冒烟测试覆盖文本输入框、图片目标和资源管理器中的热键、置顶、焦点保持、直接粘贴、托盘和开机启动。

安装验证包括全新安装、首次启动、覆盖升级和卸载。

## 11. 明确不在首版范围内

- macOS、Linux 和 Windows ARM；
- 云同步、账号系统和跨设备同步；
- 把音视频或其他文件复制进应用数据库；
- OCR、AI 总结、在线翻译；
- 剪贴板内容遥测；
- Microsoft Store 发布和商业代码签名。

这些功能需要单独设计，不影响首版完成标准。
